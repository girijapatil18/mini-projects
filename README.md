# Mini Java Projects

A collection of small Java applications demonstrating various programming concepts and practical utilities.

## Projects

### 1. Simple Calculator
A basic calculator that performs arithmetic operations.
- **File**: `Calculator.java`
- **Features**: Addition, subtraction, multiplication, division
- **Run**: `java Calculator`

### 2. To-Do List Manager
Console-based task management application.
- **File**: `TodoApp.java`
- **Features**: Add, remove, mark complete, view tasks
- **Run**: `java TodoApp`

### 3. Password Generator
Generates secure random passwords with customizable options.
- **File**: `PasswordGenerator.java`
- **Features**: Length selection, character type options
- **Run**: `java PasswordGenerator`

### 4. Number Guessing Game
Interactive guessing game with difficulty levels.
- **File**: `NumberGuessingGame.java`
- **Features**: Random number generation, attempt tracking
- **Run**: `java NumberGuessingGame`

### 5. Text File Word Counter
Analyzes text files for word statistics.
- **File**: `WordCounter.java`
- **Features**: Word count, character count, line count
- **Run**: `java WordCounter <filename>`

### 6. Simple Banking System
Basic banking operations simulator.
- **File**: `BankingSystem.java`
- **Features**: Account creation, deposit, withdraw, balance check
- **Run**: `java BankingSystem`

## Requirements
- Java 8 or higher
- No external dependencies required

## Getting Started
1. Clone this repository
2. Navigate to the project directory
3. Compile: `javac *.java`
4. Run any project: `java <ClassName>`
